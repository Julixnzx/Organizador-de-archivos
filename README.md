# 📁 Organizador Automático de Archivos

Una herramienta de utilidad desarrollada en Python diseñada para automatizar la limpieza y clasificación de directorios locales. Escanea carpetas saturadas (como Descargas) y organiza de forma inteligente los archivos por categorías, manteniendo tu espacio de trabajo ordenado y optimizado.

---

## 🚀 Características Principales

* **🔍 Clasificación Inteligente:** Detecta automáticamente las extensiones de cada archivo para ordenarlos en carpetas específicas (imágenes, documentos, scripts, ejecutables, etc.).
* **⚡ Ahorro de Tiempo:** Procesa y ordena directorios completos en cuestión de segundos.
* **💻 Ligero y Eficiente:** Script en Python puro, fácil de integrar, modificar y ejecutar en cualquier equipo.

---

## 🛠️ Tecnologías Utilizadas

* **Lenguaje:** Python 3
* **Librerías:** Manejo nativo de sistemas de archivos y directorios en Python
