📁 Organizador Automático de Archivos

Herramienta de utilidad en Python para la limpieza y clasificación de directorios

🔍 ¿Qué es este proyecto?

Una aplicación desarrollada en Python diseñada para automatizar el orden del almacenamiento local. Escanea directorios específicos y clasifica de forma inteligente los archivos (como imágenes, documentos, scripts y ejecutables) moviéndolos a carpetas estructuradas para mantener el espacio de trabajo limpio y optimizado.

🚀 Características Principales

  • Clasificación Inteligente: Detecta las extensiones de cada archivo para ordenarlos por categoría.
  • Ahorro de Tiempo: Procesa carpetas saturadas de descargas en cuestión de segundos.
  • Código Limpio y Ligero: Script en Python puro, fácil de integrar y ejecutar en cualquier equipo.
